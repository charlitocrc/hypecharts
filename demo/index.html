What ships today

80 indicators

From MA and Bollinger to Ichimoku, Supertrend and volume profiles — with editable params, per-plot styling and multiple instances of the same study.

59 drawing tools

Trend lines to pitchforks, Fibonacci/Gann, wave patterns, position and measurement tools, freehand brushes — with magnets and continuous mode.

Undo / redo

A unified named history across drawings, indicator layout and chart type. Ctrl/⌘Z everywhere.

13 chart styles

Candles in four treatments, OHLC bars, area, line, step line, baseline and HLC area — plus Heikin Ashi, Renko and Line Break transformations.

Real-time datafeed API

One small interface — history paging plus WebSocket subscribe — is all an exchange integration needs. Hyperliquid and Binance ship in-tree.

Persisted workspaces

Per-symbol drawings, indicator instances, params and pane heights survive reloads, along with zoom state.

i18n & time zones

English and 简体中文, 18 time zones, light/dark themes, full-screen and screenshot export.

Trading overlays

Position entry, PnL, liquidation and open-order lines with click-to-cancel and drag-to-modify.

Run it locally

The demo imports the library straight from src/, so every edit you make hot-reloads on the page. Run the test suite with npm test and the production build with npm run build.

git clone <this-repo> hypecharts
cd hypecharts
npm install
